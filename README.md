# 瞄准研习室

克礼无明与琪露诺瞄准教学的独立研究笔记，以思维导图和资料库两种方式阅读。

## 功能

- 两位作者各 9 个主题，点击导图节点查看归纳、适用范围和视频时间链接。
- 资料库收录 71 条已读视频及 18 张观点卡片，支持关键词搜索、主题筛选、分页和浏览器本地收藏。
- 对照双方在同一主题上的教学侧重，展示琪露诺从分解步骤到持续判断的观点演变。
- 适配桌面与手机；无依赖、无构建步骤、无服务器端数据存储。

## 本地浏览与更新

直接打开 `index.html`，或在仓库目录运行：

```shell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。页面内容保存在 `data.js`，交互逻辑在 `app.js`，样式在 `styles.css`。

GitHub Pages 使用仓库默认分支的根目录作为发布源。`.nojekyll` 使静态文件直接发布；后续推送更新后自动重新部署。

收藏保存在当前浏览器的 localStorage，不在设备间同步。页面使用本机系统字体，无需下载外部字体。

视觉采用浅灰面板、图形导航、编号标签与橙色交互标记；设计语言参考 teenage engineering 产品页，图形为本站独立绘制，与该品牌无关联。
